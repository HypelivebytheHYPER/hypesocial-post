# Figma MCP - Social Media Post Toolkit UI/UX Research

## Current System Analysis
We're building HypeSocial - a social media management platform with:
- Post composer (text + media + scheduling)
- Multi-platform publishing (Instagram, TikTok, Twitter, etc.)
- Team collaboration (People management)
- Analytics dashboard
- Blue pastel premium theme

## Questions for Figma MCP

1. What are the best practices for social media post composer UI/UX?
2. Should we have ready-to-use templates for users?
3. What features are missing from typical social media tools?
4. How to improve our current design system for better UX?
5. What smart/automated features should we add?

## Research Areas
- Post composer layouts
- Template systems
- Media upload workflows
- Scheduling interfaces
